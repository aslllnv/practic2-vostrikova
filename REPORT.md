## 12. Сравнение venv + pip и Poetry

### venv + pip

Преимущества:

- простой и понятный механизм;
- виртуальное окружение создаётся стандартными средствами Python;
- зависимости можно зафиксировать через `requirements.txt`;
- подходит для небольших учебных проектов.

Недостатки:

- `requirements.txt` содержит итоговый список установленных пакетов;
- управление группами зависимостей менее удобно;
- воспроизводимость сильнее зависит от способа формирования `requirements.txt`;
- управление обновлениями и разрешением зависимостей менее централизованное.

### Poetry

Преимущества:

- зависимости описываются в `pyproject.toml`;
- версии зависимостей фиксируются в `poetry.lock`;
- можно разделять зависимости на группы `main`, `test` и `dev`;
- удобно создавать и восстанавливать виртуальное окружение;
- можно выполнять команды через `poetry run`;
- поддерживается экспорт зависимостей в `requirements.txt`.

Недостатки:

- требуется дополнительный инструмент Poetry;
- структура проекта и управление зависимостями сложнее, чем при использовании только `pip`;
- для небольшого проекта возможности Poetry могут быть избыточными.

### Итог

Для небольшого учебного проекта `venv + pip` является простым и понятным вариантом. Poetry предоставляет более структурированный способ управления зависимостями, группами пакетов и воспроизводимым окружением.

В данной работе Poetry оказался удобнее для разделения основных, тестовых и dev-зависимостей и для восстановления окружения по `poetry.lock`.
